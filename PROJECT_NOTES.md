# EconoCausal – Project Notes

## 1. Project Overview

EconoCausal is a dynamic pricing project that uses causal machine learning to estimate how different discount offers influence customer purchasing decisions.

## 2. Project Objective

The main objective is to identify which customers are more likely to change their purchasing behavior when offered a discount. This helps businesses allocate promotional budgets more effectively.

## 3. Key Technologies

* Python – Programming language for data analysis and model development.
* Pandas – Data manipulation and analysis.
* NumPy – Numerical computations.
* Machine Learning – Learning patterns from data.
* EconML – Estimating causal effects using machine learning.
* DoWhy – Defining causal questions and testing the reliability of causal estimates.

## 4. Important Concepts

### Treatment

The discount or promotional offer provided to a customer.

### Outcome

The result we want to measure, such as whether a customer makes a purchase.

### Features

Customer characteristics and other relevant information used for analysis.

### Double Machine Learning (DML)

A causal machine learning method used to estimate the effect of a treatment, such as a discount, on an outcome, such as a purchase.

### Individualized Discount Effects

Estimating how the expected purchase behavior may change under different discount offers for different customer profiles.

## 5. General Project Workflow

1. Collect the dataset.
2. Clean and prepare the data.
3. Identify relevant features, treatment, and outcome.
4. Train the required machine learning models.
5. Estimate causal effects using DML.
6. Evaluate the results.
7. Display insights through the project dashboard.
